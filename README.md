# 鎌倉時代クイズ（小5・6月）

中学受験サポート用のクイズアプリです。小5・6月の演習（鎌倉時代1〜4）から出題します。

## 出題内容
- 源頼朝と鎌倉幕府のしくみ（執権・問注所・守護・地頭）
- 御恩と奉公、封建制度
- 承久の乱と六波羅探題、御成敗式目
- 元寇（文永の役・弘安の役）と永仁の徳政令
- 鎌倉時代の産業と文化（二毛作・宋銭・新しい仏教・金剛力士像・平家物語）
